# Klasifikasi Breast Cancer Menggunakan Machine Learning

Dataset ini berisi pengukuran numerik yang diperoleh dari citra digital hasil pemeriksaan *Fine Needle Aspirate* (FNA) pada massa atau benjolan payudara.

Data tersebut merepresentasikan karakteristik sel yang dapat digunakan sebagai fitur masukan (*input features*) untuk melatih model Machine Learning dalam membedakan tumor jinak dan ganas.

Dataset memiliki dua kelas target:

| Kelas | Keterangan |
|---|---|
| 0 | Malignant (Tumor Ganas) |
| 1 | Benign (Tumor Jinak) |

Dataset ini memiliki **30 fitur numerik** yang menggambarkan karakteristik sel, antara lain:

- **Mean Radius:** Rata-rata jarak dari pusat inti sel ke titik-titik pada batas inti sel.
- **Mean Texture:** Rata-rata variasi tingkat keabuan pada citra inti sel.
- **Mean Perimeter:** Rata-rata keliling inti sel.
- **Mean Area:** Rata-rata luas inti sel.
- **Mean Smoothness:** Ukuran variasi lokal pada panjang radius inti sel.
- **Mean Compactness:** Ukuran kekompakan bentuk inti sel.

Fitur-fitur tersebut digunakan sebagai masukan model Machine Learning untuk mempelajari pola karakteristik tumor berdasarkan data yang tersedia.
