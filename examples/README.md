# Penggunaan Google Colab sebagai Sandbox Environment

Pada mata kuliah ini, Google Colab digunakan sebagai **sandbox environment**, yaitu lingkungan komputasi berbasis cloud yang memungkinkan mahasiswa menulis, menjalankan, menguji, dan memodifikasi kode Python tanpa perlu melakukan instalasi Python maupun konfigurasi lingkungan pemrograman secara lokal.

Google Colab menyediakan lingkungan eksekusi (*runtime*) yang telah dilengkapi dengan berbagai pustaka Python untuk mendukung implementasi dan eksperimen Machine Learning.

Melalui lingkungan ini, mahasiswa dapat:
1. Menjalankan kode Python secara interaktif melalui Jupyter Notebook.
2. Menggunakan pustaka Machine Learning dan Data Science seperti NumPy, Pandas, Matplotlib, Seaborn, dan Scikit-learn.
3. Melakukan eksperimen, modifikasi kode, serta membandingkan performa algoritma Machine Learning.
4. Menampilkan hasil pengujian dan visualisasi secara langsung.
5. Menyimpan dan mengelola hasil pekerjaan melalui integrasi dengan Google Drive.

**Catatan:** Google Colab berfungsi sebagai lingkungan eksperimen yang terisolasi dari sistem lokal mahasiswa. Setiap mahasiswa menggunakan runtime dan salinan notebook masing-masing sehingga proses eksperimen dapat dilakukan secara mandiri tanpa mengubah file praktikum asli.

Untuk memulai, mahasiswa dapat menggunakan notebook yang telah disediakan dengan mengikuti petunjuk penggunaan Google Colab berikut.

## Petunjuk Menggunakan Google Colab

File praktikum disediakan dalam bentuk Google Colab dengan akses **View Only**. Setiap mahasiswa wajib membuat salinan file tersebut ke Google Drive masing-masing agar dapat mengedit dan menjalankan kode program.

**Langkah-langkah penggunaan:**

1. Buka file Google Colab melalui tautan yang telah disediakan.
2. Pastikan mahasiswa sudah login menggunakan akun Google masing-masing.
3. Pada halaman Google Colab, pilih menu **File → Save a copy in Drive**.
4. Tunggu hingga Google Colab selesai membuat salinan file ke Google Drive pribadi.
5. Buka file hasil salinan tersebut. File ini sudah dapat diedit dan dijalankan secara mandiri.
6. Kerjakan praktikum dan Mini Assignment menggunakan file hasil salinan tersebut.
7. Pastikan seluruh kode program sudah dijalankan dan hasil eksperimen ditampilkan.
8. Unduh file notebook dalam format `.ipynb` melalui menu **File → Download → Download .ipynb**.
9. Gunakan file hasil pengerjaan tersebut untuk pengumpulan melalui GitHub Pull Request dan LMS ELDIRU sesuai ketentuan yang telah ditetapkan.

**Catatan:**
- Mahasiswa tidak diperkenankan mengubah file Google Colab asli yang disediakan.
- Setiap mahasiswa wajib menggunakan salinan file pada Google Drive masing-masing.
- Berikan nama file yang mencantumkan identitas mahasiswa, misalnya `AI_Medical_Diagnosis_Nama_NIM.ipynb`.
- Pastikan file notebook yang dikumpulkan merupakan versi terbaru dan telah memuat seluruh hasil eksekusi.
